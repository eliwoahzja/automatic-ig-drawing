# Auto Sketch Android

Android 8.0+ (API 26). The app converts photos and illustrations into drawing strokes and uses the Android AccessibilityService to reproduce the strokes on a user-selected canvas. Root access is not required.

## Start

1. Install the debug APK generated by GitHub Actions.
2. Choose an image and a render mode: Sketch, Clean, Full, or Color.
3. Tap Generate sketch and inspect the preview.
4. Enable Auto Sketch in Android Accessibility Settings.
5. Open the floating controls, switch to Instagram's drawing canvas or another drawing app, and select a rectangle.
6. Move or resize the rectangle. Touches outside the handles pass through.
7. Select the brush and color in the destination app, then tap Start.
8. Pause, Resume, and Stop control the drawing. The floating controls remain draggable and resizable.

## Color layers

Select **Color** mode and generate again. The drawing engine groups the main source colors into a limited set of horizontal hatch-fill layers. Each fill is followed by a final white outline layer. Choose a thicker brush for fills and a thin brush for outlines.

Color changes are **guided, not automatic**. After the current color finishes, use the controls to press **Next color**, select the closest brush color manually in the destination drawing app, and press Start again. Repeat until all color layers are complete. No uncalibrated palette buttons are tapped automatically.

## Readable lettering

Type the exact words (and line breaks) in the **Readable lettering** field on the main screen. Adjust the text X/Y position and size, and tap **Apply lettering + regenerate**. This uses Android font outlines to produce smooth, legible letter shapes and replaces noisy traced lines in that text area. It is not OCR, and the font is an approximation.

## Current limitations

- Colored hatch lines approximate fills; they do not use a bucket-fill tool. A larger destination brush produces denser coverage.
- The destination application determines actual brush width and available colors.
- Some photographic texture and stylized text still require editing.
- Screen rotation invalidates the previous selected canvas region.
- Building an APK is not a physical-device or Instagram compatibility test.
